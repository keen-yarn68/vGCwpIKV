# 项目简介

## 核心功能
- 支持图片、视频及摄像头进行检测
- 支持选择不同模型
- 实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并查看所有检测结果
- 支持检测结果保存
- 可选择单张图片或图片文件夹进行识别
- 可选择视频文件进行识别
- 可调用本地摄像头进行识别
- 可自定义置信度和IOU阈值
- 可选择显示标签和原图
- 可选择检测模型

## 适用场景
- 姿态识别与动作检测
- 计算机视觉研究
- 人机交互应用
- 行为分析系统
- 智能监控场景

## 技术特点
- 基于YOLOv8的关键点姿态分类
- 使用Python开发环境
- 包含PyQt5图形界面
- 支持多种输入源（图片、视频、摄像头）
- 提供完整的源码和模型文件
- 包含详细运行教程
